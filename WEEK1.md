# Week 1 — Foundation Tasks

## Day 1–2: Python fluency
- [ ] Review data structures (list, dict, set, tuple) and comprehensions
- [ ] Practice functions with type hints and docstrings
- [ ] OOP: classes, inheritance, `__init__`, dunder methods
- [ ] Virtual environments: `python -m venv .venv`, activate, install from requirements.txt

## Day 3: ML fundamentals
- [ ] Supervised vs unsupervised learning
- [ ] Train/test split, stratification, why we don't train on test data
- [ ] Metrics: accuracy, precision, recall, F1, RMSE — when to use each
- [ ] Run `baseline_pipeline.py` and review `EVAL_REPORTS/week1_baseline.json`

## Day 4: Git/GitHub
- [ ] `git init`, first commit of baseline pipeline
- [ ] Branch strategy: `main` + feature branches
- [ ] Push to GitHub, open a PR (even if to your own repo)
- [ ] Commit message conventions (imperative mood, subject line < 50 chars)

## Day 5: Linux basics
- [ ] Shell navigation: `pwd`, `ls`, `cd`, `mkdir`, `rm`, `cp`, `mv`
- [ ] File permissions: `chmod`, `chown` (conceptual on Windows)
- [ ] Basic scripting: a `.sh` or `.bat` that runs the pipeline

## Day 6–7: Sunday weekly ritual (60 min)
- [ ] Review: what did I ship this week?
- [ ] Plan: Week 2 goals
- [ ] Learn: one new concept (e.g., bias/variance tradeoff)
- [ ] Commit: update PROGRESS.md + LEARNING_LOG.md

## Gate criteria (end of Week 4, not Week 1)
- [ ] Working local ML pipeline
- [ ] Eval report with accuracy/F1
- [ ] Cost/latency numbers logged
- [ ] Runbook documented
